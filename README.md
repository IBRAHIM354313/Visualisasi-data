# 📊 Portofolio Pengolahan Data & Administrasi Yayasan

Repositori ini berisi kumpulan laporan analisis dan pengolahan data berbasis visualisasi yang saya susun selama mengikuti pelatihan. Proyek ini merepresentasikan kemampuan saya dalam mengolah data mentah menjadi informasi strategis yang siap digunakan untuk kebutuhan administrasi dan pengambilan keputusan di organisasi/yayasan.

## 📂 Daftar Dokumen & Cakupan Kompetensi

Berikut adalah detail dari laporan PDF yang ada di dalam repositori ini:

1. **LAPORAN VISUALISASI DATA 1.pdf**
   * **Fokus:** Analisis tren data operasional dan visualisasi metrik utama yayasan.
   * **Keahlian yang Ditunjukkan:** Penyusunan struktur laporan yang formal, pembuatan grafik yang informatif, dan penyajian data ringkas (*executive summary*).

2. **tugas p1-visualisasi data.pdf** & **p2-visualisasi data_2C2230002.pdf**
   * **Fokus:** Studi kasus pengolahan data administratif dan teknis penataan visual agar data lebih mudah dibaca oleh pihak manajemen/donatur.
   * **Keahlian yang Ditunjukkan:** Manajemen database, pembersihan data (*data cleaning*), dan akurasi pelaporan.

## 🛠️ Tools & Keterampilan Teknis
* **Pengolahan & Analisis Data:** Microsoft Excel / Google Sheets (Formula, Pivot Table).
* **Pelaporan & Visualisasi:** Desain dokumen laporan formal berbasis PDF (struktur data runut, grafik, dan tabel).
* **Administrasi Digital:** Manajemen file berbasis *cloud* dan kontrol versi menggunakan GitHub.

---
*Catatan: Semua data sensitif, nama personal, dan nominal angka di dalam laporan ini telah disamarkan/diubah menjadi data fiktif demi menjaga kerahasiaan dan privasi organisasi.*
